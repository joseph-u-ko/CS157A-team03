# CS157A-team03
## Project Description - 
PokéTrader is a website for Pokémon enthusiasts who just want to collect Pokémon cards without having to spend too much money on singles and packs. The website offers a way to open virtual packs of real sets in the Pokémon Trading Card Game and store them in a virtual “binder” for their collection. Additionally, it also allows users to engage in trades for cards that they want.

The primary goal of PokéTrader is to provide an accessible, free experience to the Pokémon Trading Card Game. Pokémon products (booster packs, booster boxes, booster bundles, Elite Trainer Boxes (ETBs), collector boxes & tins, etc.) are relatively expensive for the average consumer to purchase. 

The major stakeholders are primarily Pokémon fans, who will be the main target audience of this website application.

Our specific innovation is to provide more variety to enjoy the Pokémon Trading Card Game experience. Pokémon already has their Pokémon Trading Card Game Pocket, which is only available on mobile devices. We are providing a web-based application which can reach computer users who want to take part in Pokémon.

## Project Download Instructions -
Requirements:
- Eclipse IDE
- Tomcat v10.1

Step 1.) Setup a Dynamic Web Project in Eclipse.<br>
Step 2.) Download MysqlCon.java, 3-Tier-poketrader.jsp, poketrader_styles.css<br>
Step 3.) Place the following files into the specified project directories<br>
- MysqlCon.java into /java directory
- 3-Tier-poketrader.jsp into /webapp
- poketrader_styles.css into /webapp
<br>

Step 4.) Create a new server (select Tomcat v10.1)<br>

Step 5.) Start server<br>

Step 6.) Run 3-Tier-poketrader.jsp and select "Run on Server"
